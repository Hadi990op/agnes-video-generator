# Release v5.6.0 — Midnight Design System UI Redesign

> Release date: 2026-08-11

## Overview

v5.6.0 is a **minor version** that redesigns the entire frontend with the **Hallmark "Midnight" design system** — an atmospheric, cinematic look across all tabs, forms and progress views.

## Usage

From v5.5.0:

```bash
git pull
.venv/bin/pip install -r requirements.txt
./start.sh
```

## What's New

### Features & Improvements

- **Midnight design system** — complete frontend redesign with an atmospheric dark theme, refined typography, spacing and visual hierarchy across all task tabs, configuration panels and progress views.
