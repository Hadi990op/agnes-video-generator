# Release v5.3.1 — Prompt Examples in All Task Forms

> Release date: 2026-08-07

## Overview

v5.3.1 is a **patch release** that adds **prompt-example guide links** to all four task-type forms across all 13 languages, plus a unified API-key error message and small official-site integration touches.

## Usage

From v5.3.0:

```bash
git pull
.venv/bin/pip install -r requirements.txt
./start.sh
```

## What's New

### Features & Improvements

- **Prompt examples in task forms** — each task-type form (Simple / Creative / Manuscript / Anchor) shows a guide link to prompt examples, localized for all 13 languages.
- **Unified API-key error message** — consistent key-configuration error text across the app and API docs.
