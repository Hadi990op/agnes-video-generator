# Release v4.0.0 — 13-Language Web UI (6 New European Languages)

> Release date: 2026-07-03

## Overview

v4.0.0 is a **major version** that extends the Web UI from 7 to **13 languages**: German, French, Dutch, Spanish, Portuguese and Italian join the existing 中文 / English / Русский / 日本語 / 한국어 / Bahasa Melayu / Bahasa Indonesia. Every interface element (forms, config panels, task progress, subtitles, i18n keys) is localized for the new languages.

## Usage

From v3.5.0:

```bash
git pull
.venv/bin/pip install -r requirements.txt
./start.sh
```

## What's New

### Features & Improvements

- **6 new UI languages** — German (Deutsch), French (Français), Dutch (Nederlands), Spanish (Español), Portuguese (Português) and Italian (Italiano), bringing the total to 13 fully localized languages.
- **Full coverage** — all tabs, configuration panels, task status, progress messages and error text are localized; language can be switched anytime in the header.
