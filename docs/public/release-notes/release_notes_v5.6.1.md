# Release v5.6.1 — Light/Dark Dual Mode + Theme Toggle

> Release date: 2026-08-12

## Overview

v5.6.1 is a **patch release** that adds a **light/dark dual-mode** to the Midnight design system with a theme toggle in the UI, and fixes sidebar overflow on the redesigned pages.

## Usage

From v5.6.0:

```bash
git pull
.venv/bin/pip install -r requirements.txt
./start.sh
```

## What's New

### Features & Improvements

- **Light/dark dual mode** — the Midnight design system now supports both light and dark themes with a one-click toggle.
- **Theme toggle UI** — quick theme switching in the header.

### Bug Fixes

- Sidebar overflow fixed on the redesigned desktop layout.
